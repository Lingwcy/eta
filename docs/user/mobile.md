# 使用 eta-mobile 连接 Bot

eta-mobile 在 iOS 和 Android 手机上连接已部署的 Eta Bot。首次打开应用时，填写服务器地址和访问令牌，然后验证并连接。手机需要能够访问 Bot；模型和模型凭据由 Bot 提供。

在会话菜单中选择项目，或在 Bot 的工作空间根目录下创建项目，然后新建会话并发送消息。输入框下方可以选择模型、思考等级和 Bot 允许的沙盒策略。已有会话的设置需在任务结束后修改。

点击输入框中的图片入口从相册选择图片，可预览、移除，也可以不输入文字直接发送。每条消息最多 4 张、单张不超过 8 MB，总计不超过 24 MB；支持 JPEG、PNG、GIF 和 WebP，需要选择支持图片的模型。未发送的图片随草稿保存在手机上；接收状态不明时，重试会保留原图片。

任务执行过程中可以查看回复和工具结果，处理审批请求，或停止任务。Bot 开启自动审查时，卡片会显示审查进度和转交给你的原因；Git 写入请求可以选择本次运行内允许；期间任何申请相同范围的命令都能写共享 Git 对象库，请只在信任当前任务时使用。运行时可展开自动审查记录，查看决定、理由、模型和授权范围。归档的会话可以在菜单的归档列表中找到并取消归档。需要人工恢复的任务会显示恢复入口或阻塞原因。已移除的 worktree 会话仍可查看历史，执行目录已移除时不能发送。

Bot 支持输入队列时，任务执行中也能发送消息：普通发送为「补充指令」，在当前请求和工具轮结束后的下一个安全边界生效；「排队执行」等当前工作及所有补充指令结束后再处理。两者都不会立即中断正在执行的工具或审批等待，需要取消时仍可停止。

待处理消息可逐条「取回」，文字和图片会补回当前草稿；已经生效的消息无法撤回。停止或最终失败后的未执行内容仍可取回再发。每个聊天最多等待 32 条消息，并受附件总大小限制；队列满或发送被拒绝时保留草稿。旧 Bot 不支持执行中发送，需要升级后使用。

关闭应用、锁屏或断开连接后，Bot 已接收的任务继续运行。重新打开应用后，会话从 Bot 读取最新状态。需要取消任务时，请在会话中选择停止。

消息提交后如果网络中断，接收状态可能暂时无法确认。使用「重试并确认接收」确认原消息；这个操作沿用原请求标识，不重复创建同一任务。没有网络时可以编辑草稿，联网后再发送。

在连接设置中可以修改服务器地址和令牌、重新连接或断开连接。清除连接和手机缓存会移除手机上的连接、目录缓存和草稿，Bot 上的会话和任务仍会保留。目前支持连接一个 Bot。
