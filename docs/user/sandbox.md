# 选择代理的访问范围

在聊天输入框中选择「只读」「工作区沙盒」或「完全访问」。新会话默认使用工作区沙盒；可在「设置 → 权限」修改之后创建的本机会话的默认策略。已有会话保存自己的策略，切换前需要停止线程及其子智能体。子智能体继承主会话的策略。

- **只读**：代理可以检查工作区文件。编辑文件和运行命令前需要您批准。
- **工作区沙盒**：代理可以在工作区内读写文件、运行本地命令并联网。访问工作区外的文件需要您批准。
- **完全访问**：移除代理文件工具和命令的文件系统及网络边界，可访问电脑上的文件和互联网。

待审批卡片会显示操作、完整参数，以及额外的读取、写入和联网范围。选择「仅批准此次操作」或「拒绝」。批准不会改变会话策略，也不会授权下一次工具调用。停止任务或重启 Eta 后，已经批准的临时权限失效；未完成任务不会自动恢复。

受限策略允许访问运行命令所需的系统程序和库，以及会话的临时文件。Eta 的数据目录和常见凭证目录仍受保护。沙盒约束代理的内置文件工具、命令及子进程；Eta 连接模型服务和 Bot 收发消息仍使用主程序的连接。

macOS 和 Linux 支持受限执行。Linux 需要可用的系统沙盒后端；Bot 镜像包含原生后端。当前 Windows 版本尚不支持受限执行。后端缺失、内核不支持或启动失败时，Eta 会显示原因并阻止任务，历史仍可查看。Eta 不会自动改为完全访问。
