# 用 Eta 完成工作

[English](desktop.md) · 简体中文

安装和首次使用请看 [README](../../README.zh-CN.md)。

## 聊天与本地数据

需要一边聊天一边查资料时，使用 **Cmd/Ctrl+T** 打开网页标签，在地址栏输入网址或搜索内容。

**新聊天**会返回已有的未提交会话，保留草稿和项目选择；提交后可以再开始新的聊天。切换标签会保留各自的草稿；关闭聊天标签不会删除历史，已提交的任务也会继续执行。使用 **Cmd/Ctrl+W** 关闭标签，**Cmd/Ctrl+Shift+T** 重新打开。

右键已保存的聊天，可以重命名、调整项目归属、归档或恢复、在新的 Eta 窗口中打开，以及永久删除本地历史。调整项目归属不会改变 agent 执行任务的目录。“打开方式”可用默认或指定应用打开主会话 JSONL 记录，建议使用文本编辑器查看。

在**设置 → 应用 → 存储**中查看本地会话占用，并定位会话目录，便于检查或备份。

备份时保留整个会话目录，不要只复制主 JSONL 记录。子智能体共用这份记录，恢复任务还需要同目录的状态文件。打开未完成的会话时，需要明确选择恢复或停止。

## 定时任务

打开左侧「定时任务」并选择「新建任务」，指定执行工作区、内容和时间；也可右键已有聊天选择「添加定时任务」。计划留在该聊天中，按会话聚合显示，在右侧定时任务栏编辑、暂停、恢复、运行一次或删除。支持一次、间隔、每天和每周；间隔至少 5 分钟，每天和每周明确指定时区。

请 agent 安排任务时，它先提出待确认提案。检查内容、规则和执行环境后批准才会生效；拒绝不会创建计划。修改提案会产生新提案，旧提案失效。无人确认的提案默认 24 小时后过期。自动执行使用该会话当前的模型、工作区与审批设置，可能修改文件和消耗模型额度。

忙时不打断现有任务，空闲后只补发最近一次，超过默认 24 小时的执行不会补发。执行失败不会自动重跑。归档会话暂停计划，恢复会话不会自动恢复计划；关闭聊天标签不暂停计划。暂停或删除计划只停止后续触发，已开始的任务请在聊天中停止。管理请求显示「正在处理」时，原计划状态仍有效，等待核对结果后才会显示成功。

Eta 退出或电脑睡眠时不会执行；重新打开后按上述补发策略处理。macOS 关窗后保留运行。Windows 默认关窗退出，可在「设置 → 应用 → 关于 → 后台运行」开启「关闭窗口后后台运行」，通过可见托盘打开或退出。显式退出始终停止本地任务。

Bot 计划保存在服务器，Desktop 断线或退出不会停止它们。断线时显示可能过期的缓存，不能创建或修改；需要支持定时任务的 Bot 版本，不会改到本地执行。实际工作区不可用或会话需要恢复时，任务显示阻塞，处理后再继续。

## 在独立 worktree 中开始

发送新聊天的第一条消息前，可在项目旁的工作区配置中开启“新 worktree”，通过分支菜单选择已有分支或填写新分支名。Eta 在发送时创建独立目录；当前目录未提交的改动不会带过去。创建或发送失败时保留草稿，重试会复用已创建的工作区。已被检出的分支和远端跟踪分支作为新分支的基线。会话发起后工作区配置自动隐藏。

Git 写入的审批和本次运行内授权见[访问范围说明](./sandbox.md#在-worktree-中提交)。关闭聊天标签或归档会话不会删除 worktree。

Desktop 默认把 worktree 存放在 Eta 数据目录旁的独立管理目录，保护整个数据目录；已有会话的执行目录不会自动迁移。

## 查看 GitHub PR 与 Issue

右侧栏有可用内容时默认展开。选择 GitHub 标签后，在顶部功能区切换 PR / Issues，默认查看 Open 列表；选项菜单中保留仓库选择、状态筛选、刷新和访问状态。点击条目在外部浏览器打开。项目有 GitHub remote 且宿主支持查询时才显示 GitHub 标签；当前会话有子智能体时才显示子智能体标签。查看仓库以会话的实际执行工作区为准。**Alt+←** 折叠或重新打开当前右侧栏，也适用于网页与设置标签。

公开仓库可匿名查看；私有仓库或更高访问额度需要在本机（Bot 项目则在服务器）运行 gh auth login，然后刷新 GitHub 侧栏。GitHub 访问身份独立于模型的 GitHub Copilot 登录。Bot 未连接时缓存标为过期，刷新及写入不可用。

## 技能

技能为 agent 提供可复用的指令。每个技能放在一个包含 `SKILL.md` 的文件夹中：

| 适用范围 | 目录                       |
| -------- | -------------------------- |
| 个人     | `~/.agents/skills/`        |
| 当前项目 | 项目内的 `.agents/skills/` |

同名技能以项目版本优先。在**设置 → 技能**中添加自定义目录、查看发现错误、启用或停用技能，以及打开技能文件夹。打开尚不存在的技能目录时会自动创建。

通过输入框的技能入口、**Cmd/Ctrl+Shift+K**，或在请求中写出技能名来选择：

```text
$better-readme 重构这个项目的 README。
```

这个例子需要先安装名为 `better-readme` 的技能；Eta 不自带该技能。

Eta 先向 agent 提供技能名称和描述，使用时才加载正文，再按需读取附属资源。已加载的指令会随会话保存，重启和压缩上下文后仍可使用。要加载更新后的版本，先在输入框中移除已加载的技能，再重新选择。技能使用当前可用的工具和本机依赖，不会获得额外权限。

## 子智能体

主 agent 可以将工作交给子智能体，在独立子会话中执行。有委派任务后，使用 **Alt+←** 打开右侧栏，选择任务查看对话和已汇报的进展。执行中也可发送消息调整方向或请求汇总；向已结束或暂停的任务发消息，会继续同一个子会话。

独立子智能体接收交给它的任务与项目指令；分叉子智能体会继承创建时的对话历史。

在**设置 → 子智能体**中创建预设，设置任务指令、思考级别和候选模型。执行任务的子智能体默认直接完成工作；需要协调其他智能体的预设可开启继续委派。模型范围默认跟随当前主模型，可通过模型选择器启用其他模型。嵌套深度和并发上限为全局设置；并发按各会话的智能体树单独计数，超出的子任务会排队。

| 模式 | 委派方式                                       |
| ---- | ---------------------------------------------- |
| 按需 | 主 agent 在有需要时委派任务。                  |
| 编排 | 子智能体执行工具，主会话负责交流、协调和汇总。 |

编排模式下，主会话在协调回合之间可以接收新消息，子任务继续执行。子任务结束时，主会话会自动被唤醒并汇总结果。

等待超时不会停止子任务。停止任务会取消执行，不会生成最终答复，但会保留已汇报的进展和历史。停止主任务会停止整个子任务树。要继续未完成的工作，请明确恢复，或在停止后发送新任务。
